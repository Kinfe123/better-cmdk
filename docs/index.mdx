# better-cmdk

A beautiful command palette component for React, built on cmdk and Radix UI. Styled with Tailwind CSS v4 using the shadcn/ui design system.

better-cmdk is documented around capabilities, workflows, and the configuration decisions that affect runtime behavior. The pages below are organized so you can find a working answer before you need to inspect source files.

New here? Jump to the [quickstart](/docs/quickstart) for a minimal working example, or [installation](/docs/installation) for setup details.
