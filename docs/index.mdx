# Introduction

better-cmdk is a React command palette that goes beyond basic search. It gives you a polished, accessible `CommandMenu` built on top of [cmdk](https://cmdk.paco.me) and [Radix UI](https://www.radix-ui.com/), styled with Tailwind CSS v4 and the shadcn/ui design system — so it fits naturally into any modern React app without fighting your existing styles.

The library ships two complementary usage modes. The declarative `actions` prop is the quickest path: define your commands as a typed array and pass them in. For teams migrating from shadcn/ui or needing full control, you can compose the raw `CommandInput`, `CommandList`, `CommandGroup`, and `CommandItem` primitives directly as children. Both modes come with built-in AI chat, mobile sheet support, keyboard shortcuts, and themeable CSS tokens — all under the isolated `.bcmdk-root` scope so your global styles stay untouched.

If you're new here, [Installation](/docs/installation) covers prerequisites and stylesheet setup, and [Quickstart](/docs/quickstart) gets you to a working command palette in minutes. The [Features](/docs/features) section goes deeper on AI chat and the action model.
